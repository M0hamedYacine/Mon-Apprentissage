Application météo simple développée avec HTML, JavaScript et Tailwind CSS, utilisant l’API OpenWeather.
Le tutoriel d’origine était en HTML, CSS et JavaScript ; afin de mieux comprendre JavaScript et de pratiquer Tailwind CSS, j’ai réalisé moi-même le rendu visuel avec Tailwind.

Ce projet m’a permis de mieux comprendre :

la manipulation du DOM (querySelector, innerHTML, className),

la gestion des événements (addEventListener),

la modification dynamique des éléments HTML (ex. meteoIcon.src),

l’utilisation d’une API externe avec fetch, async et await.
