Ce projet est un générateur de mots de passe aléatoires développé avec HTML, JavaScript et Tailwind CSS.
L’objectif pincipal es toujour  renforcer ma compréhension du JavaScript.

À travers ce projet, j’ai réutilisé et consolidé plusieurs propriétés déjà vues dans les projets précédents :

getElementById pour sélectionner des éléments HTML,

value pour lire et modifier le contenu d’un champ input,

addEventListener pour gérer les actions utilisateur (clic),

innerHTML pour modifier dynamiquement le contenu d’un élément.

J’ai également mieux compris de nouvelles notions, notamment :

l’utilisation de Math.random() et Math.floor() pour générer des caractères aléatoires,

la construction d’un mot de passe à partir de plusieurs ensembles de caractères (majuscules, minuscules, chiffres, caractères spéciaux),

la logique de boucle permettant de générer une chaîne jusqu’à une longueur définie.

Ce projet m’a aussi permis de découvrir l’API du navigateur navigator.clipboard, utilisée pour copier automatiquement le mot de passe généré, ainsi que la gestion de petits effets visuels et temporels avec :

style pour appliquer des animations simples,

setTimeout pour exécuter des actions différées (réinitialisation de l’input après la copie).
