# 🌐 Immersion Web : HTML, Tailwind CSS & JS

Ce dossier contient les projets concrets réalisés lors de mes deux dernières semaines d'apprentissage.

## 📝 Carnet de bord (Semaines 01 & 02)

### Phase 1 : Consolidation théorique (LabEx.io)
Révision structurée des bases HTML5/CSS3, initiation à Tailwind CSS et aux fondamentaux du JavaScript.

### Phase 2 : Pratique & "Traduction" Technique
Pour valider mes acquis, j'ai suivi des tutoriels YouTube en ajoutant une difficulté supplémentaire :
* **Challenge Personnel :** Suivre des tutos basés sur du CSS classique et les **adapter en temps réel avec Tailwind CSS**. 
* **Objectif :** Comprendre l'interactivité avec **JavaScript** tout en maîtrisant le styling utilitaire. 
* **Résultat :** Une meilleure compréhension des sélecteurs, du DOM et de la logique de composants.

### Phase 3 : Maîtrise du Workflow avec Git
Parallèlement, j'ai poussé l'apprentissage de Git au-delà des bases pour gérer mon laboratoire :
* **Bases :** Init, add, commit, status, log.
* **Navigation :** Gestion des branches et fusion.
* **Maintenance :** "Remonter le temps" avec `revert` et `reset`.
* **Optimisation :** Modification et fusion de commits via le `rebase`.
