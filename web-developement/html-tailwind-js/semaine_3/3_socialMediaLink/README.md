📋 Exercice : Social Links Profile (Frontend Mentor)

Ceci est un exercice pratique réalisé dans le cadre de mon apprentissage du développement Front-end. L'objectif était de reproduire un composant "Social Links" en suivant une maquette précise.
🎯 Objectifs de l'exercice

    Pratiquer l'intégration d'une carte de profil en mode sombre (Dark Mode).
    Maîtriser les listes de navigation (<ul>, <li>) et leur stylisation.
    Appliquer des micro-interactions fluides au survol (hover states).

📸 Aperçu du rendu
💡 Ce que j'ai mis en pratique
1. Structure Sémantique

Même pour un petit exercice, j'ai choisi d'utiliser des balises sémantiques comme <main> pour le contenu principal et <nav> pour la liste des liens sociaux, ce qui est essentiel pour l'accessibilité.
2. Design System & Couleurs

L'exercice imposait une palette de couleurs spécifique. J'ai utilisé Tailwind pour gérer ces contrastes :

    Utilisation du vert fluo hsl(75, 94%, 57%) comme couleur d'accentuation.
    Gestion des arrondis (rounded-md, rounded-full) pour coller au design original.

3. Workflow de développement

    Mobile-First : Intégration pensée d'abord pour le mobile avant de l'ajuster pour le desktop.
    Git/GitHub : Versionnage régulier de l'exercice pour garder une trace de mon évolution.

🛠️ Outils utilisés

    HTML5
    Tailwind CSS

📖 Comment l'utiliser

    Clone le dépôt.
    Ouvre le fichier index.html dans ton navigateur.
    Aucun configuration prealable
